Real-ESRGAN (realesrgan-ncnn-vulkan and the realesrgan-x4plus model)
https://github.com/xinntao/Real-ESRGAN

Not shipped with Lantern Engine. The launcher downloads the official release v0.2.5.0 from GitHub
(checked by SHA-256) when a player builds the 4K menus, and runs it on that player's own game files.
realesrgan-ncnn-vulkan is built on ncnn by Tencent (https://github.com/Tencent/ncnn, BSD 3-Clause).
